## Overview

Cartify is a frontend e-commerce interface built with HTML, CSS, and JavaScript. It presents a shopping-style homepage with navigation, promotional sections, product and category imagery, and responsive layout patterns. The project focuses on recreating common storefront design patterns while practicing core frontend development.

## Features

- **Storefront navigation:** Shopping-style header, search area, account links, and cart presentation.
- **Promotional sections:** Homepage content organized around offers and shopping categories.
- **Product and category displays:** Image-led cards for gaming, home essentials, fashion, school supplies, and gift ideas.
- **Responsive layout:** CSS Grid, Flexbox, and media queries support different screen sizes.
- **Visual interaction:** Hover states and lightweight client-side interactions.
- **Iconography:** Font Awesome icons are used in the interface.

> Cartify is documented as a frontend demonstration. It does not claim backend services, authentication, checkout, payment processing, or persistent cart functionality.

## Run Locally

```bash
git clone https://github.com/mdnav/cartify.git
cd cartify
```

Open `index.html` in a modern browser. The Font Awesome stylesheet is loaded from a CDN, so an internet connection is needed for those icons.
